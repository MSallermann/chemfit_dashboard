# Changelog

All notable changes to ChemFit Dashboard are documented here.

## 0.1.0 — 2026-11-19

Initial public release.

- Browse individual ChemFit evaluations, JSONL trajectories, and collections.
- Inspect component hierarchies, recorded values, statuses, and data flow.
- Search across evaluations and analyze collection-wide results.
- Plot multiple numerical series and export plot data and images.
- Extract arbitrary fields and components to CSV or JSONL from the GUI or CLI.
- Save and reuse extraction configurations with wildcard component selection.
- Customize themes, density, font sizing, and workspace layout.
